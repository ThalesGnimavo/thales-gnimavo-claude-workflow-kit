# my-projects

Every project you run with this kit lives here, in its own folder: `my-projects/<name>/`.
Nothing of yours should live anywhere else on the machine. Each folder is its own git
repository with its own `CLAUDE.md` and `casp/`; the kit's rules at the root apply to all of
them. Create one with `/thales:new-project <name>`, or move an existing folder here.

---
